## 1. PROJECT OVERVIEW
### The Lived Problem (Within Reach Theme)
ProReady was engineered out of the raw, first-hand pain of navigating a brutal entry-level job market. Traditional corporate recruitment relies heavily on automated applicant tracking systems (ATS) that scan PDF documents for generic text keywords. High-potential young professionals, diverse career changers, and non-technical majors (e.g., International Affairs, Public Policy) possess elite critical-thinking and structural analysis capabilities but are systematically cancelled by automated algorithms before a human recruiter ever reviews their brain. If a candidate attempts to submit an introductory policy resume for an Associate Solutions Architect or Cybersecurity Analyst role today, the system filters them out instantly due to a lack of technical keywords—creating an unbreakable Catch-22 loop.

### The ProReady Solution (Community Resilience)
ProReady restores community resilience by providing an open-access, browser-native **Career Sandbox & Simulation Forge**. Instead of taking intimidating, multiple-choice tests or writing cover letters that go unread, users enter our free self-service tracks to log practical "flight hours" solving industry-standard crisis scenarios. The platform leverages a unique **Crowdsourced Civic Feed** where local minority-owned businesses and neighborhood non-profits log real-world operational bottlenecks for free. Underemployed learners team up with peers to resolve the briefs, automatically generating an un-cheatable public **Evidence Share-Link** (`proready.io/evidence/userId`) backed by an interactive **AI Viva Voce countdown verification loop**. Candidates drop this link at the absolute top of their traditional job applications and LinkedIn profiles, weaponizing their actual capabilities to force human review and bypass automated keyword filters entirely.

## 2. DESIGN DECISIONS & ARCHITECTURAL TRADE-OFFS
### High-Fidelity Frontend Prototype Framework
For this MVP hackathon deployment, ProReady is engineered as a high-fidelity frontend-only application container built using Vite + React + TypeScript + Tailwind CSS. All underlying data matrices, database tables, and large language model execution streams are mocked behind modular, well-named asynchronous boundaries. This deliberate design decision optimized development velocity and guaranteed strict UI performance before the October 23 deadline, allowing live production AWS SDK clients to drop in seamlessly later without altering interface elements.

### Interface Boundaries & Client-Side Stubs
To maintain a lean footprint during this prototype phase, the PDF trait-mapping parser and CSR certificate generator run via high-fidelity client-side stubs rather than a heavyweight machine learning backend. The resume upload zone maps keyword properties directly to structural engineering values (e.g., "Policy Analysis" to "Systemic Logic") within our React states to cleanly model the interface intent for the judges. Similarly, the Corporate Volunteer certificate module processes real-time session duration logs to generate a portable download asset, leaving a modular integration seam where cryptographic verification protocols can plug in downstream.

### The Corporate Volunteer Guild Integration
To scale human networks without hitting corporate bureaucratic red tape, the platform incorporates a zero-cost Corporate Volunteer Guild layer. Large technology enterprises (such as AWS and HP) allocate mandatory corporate pro bono hours to staff annually. ProReady interfaces with these employees to join our student workspace containers as high-level residency advisors. Because the projects are crowdsourced local civic problems or historical open-source case studies, zero proprietary company IP is touched. The platform automatically monitors session metrics and generates a verified CSR Impact Certificate for their internal corporate HR departments, while the young builder exits with a direct industry endorsement.

## 4. CODE EXPLORATION & AWS SERVICE ARCHITECTURE SEAMS
The codebase features explicit, production-ready asynchronous service seams demonstrating exactly where serverless AWS infrastructure integrates to drive global scalability:

### Feature 1: Asynchronous AWS Bedrock AI Viva Voce Agent (`src/lib/bedrockVivaAgent.ts`)
Houses the explicit configuration scaffolding for the `@aws-sdk/client-bedrock-runtime` client library. Upon candidate sandbox challenge submission, this interface routes a prompt script instructing an AWS Bedrock model (such as Amazon Titan or Claude 3) to parse user inputs and automatically generate 3 custom technical questions. The UI view (`src/components/VivaVocePanel.tsx`) subjects the candidate to a strict 90-second countdown window per question, capturing their verbal reasoning logic to guarantee code authenticity and eliminate AI plagiarism.

### Feature 2: Trait-Focused Employer Alignment Index (`src/components/ScoreMeter.tsx`)
Completely strips out traditional, punitive pass/fail numerical testing grids that induce evaluation anxiety. It renders a clean, multidimensional radar chart that maps candidate troubleshooting logs directly against the core structural building codes of the **AWS Well-Architected Framework** (Security Isolation, Cost Optimization, and Operational Excellence) to reveal their ideal workflow placement.

### Feature 3: Serverless 1-Click Resume Parser (`src/lib/resumeParserEngine.ts`)
To eliminate application exhaustion, this module scaffolds the technical pipeline where a single PDF document upload triggers an AWS Lambda function integrated with Amazon Textract. It dynamically strips text strings to instantly populate React profile states with zero manual entry requirements.

### Feature 4: Scalable NoSQL Data Architecture (`src/data/dynamoDbSchema.json`)
A production-ready JSON document schema defining our Amazon DynamoDB database model. It establishes explicit table partitions and secondary global indices tracking candidate identifiers (`userId`), capability alignment parameters, and voice-defense transcription metrics for serverless corporate scale.
